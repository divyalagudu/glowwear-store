# GlowWear — Women’s Blouses

## Run in VS Code (Mac)
```bash
cd backend
npm install
npm start
```
Open **http://localhost:5050**. Keep the terminal running.

This version uses port 5050 by default because macOS may reserve port 5000 for AirPlay/AirTunes.

The shop works without MongoDB using a local in-memory demo product catalog and local blouse images. Configure MongoDB later for persistent users, products and orders.


## Product images
The demo catalog includes local blouse photography under `frontend/assets/`.
Replace these files with your own licensed product photos before commercial launch.
